# crosspointTH v1.6.0-th.1.0 (Pre-release)

![อัปเดต Firmware ภาษาไทย v1.6.0-th.1.0 สำหรับ XTEINK X3 และ X4](https://raw.githubusercontent.com/JTIAPBNAI/CrosspointTH/v1.6.0-th.1.0/docs/images/crosspoint-th/update-firmware-v1.6.0-th.1.0.png)

รุ่นทดสอบล่วงหน้าสำหรับ XTEINK X3/X4 ที่เพิ่มชุด Apps โดยแยกออกจาก reader core และยังคงความสามารถด้าน
ฟอนต์ การตัดคำ และการจัดวางภาษาไทยของ crosspointTH 1.5

## ฟีเจอร์ใหม่

- **Clock + ปฏิทินไทย** แสดงเวลา ปฏิทินรายเดือน และปี พ.ศ.
- **Weather** ใช้ Open-Meteo โดยไม่ต้องมีบัญชี เลือกได้ 8 พื้นที่ในไทย และเก็บข้อมูลล่าสุดไว้ใน SD card
- **Pomodoro** พร้อมตัวเลขขนาดใหญ่ขึ้นเพื่ออ่านจากระยะไกล
- **Flashcards** อ่าน deck แบบ CSV จาก SD card ทีละบรรทัด พร้อมระบบทบทวนแบบ SM-2 ขนาดเล็ก
- **Games**: 2048, Sudoku, Minesweeper, Caro และหมากฮอสไทย
- **Sleep Screen: Calendar + Weather** แสดงเวลา ปฏิทินไทย แบตเตอรี่ และสภาพอากาศล่าสุดจาก cache

บน X3 นาฬิกาใน Sleep Screen จะปลุกเครื่องสั้น ๆ ทุก 5 นาทีเพื่ออัปเดตหน้าจอ แล้วกลับเข้าสู่ deep sleep
ทันที โดยไม่เปิด Wi-Fi ส่วน X4 จะคงหน้าจอแบบ static เนื่องจากวงจรตัดไฟ MCU ระหว่าง deep sleep

หลังติดตั้ง ให้ตั้ง **Settings → Customise Status Bar → Clock UTC Offset → UTC+7:00** และเลือก
**Sync clock now** หนึ่งครั้งเพื่อให้เวลาไทยถูกต้อง

## การแก้ไขสำคัญ

- แก้ตัวอ่านผล Open-Meteo ให้ดึงค่าตัวเลขจาก `current` แทนการหยุดที่ข้อความใน `current_units`
- แสดงสถานะ Wi-Fi ระหว่างรีเฟรชอากาศเพื่อช่วยตรวจสอบการเชื่อมต่อ
- ขยายตัวเลขนับถอยหลัง Pomodoro เป็นฟอนต์หนา 18 จุด
- แยก weather cache สำหรับใช้ร่วมกันระหว่างแอป Weather และ Sleep Screen โดยไม่เปิดเครือข่ายขณะหลับ

## ทรัพยากรและการตรวจสอบ

- Application: 6,164,729 / 6,553,600 bytes เหลือ 388,871 bytes
- Static RAM: 52,060 / 327,680 bytes (15.9%)
- ผ่าน unit tests 158 รายการ, static analysis และ release safety gate
- ไม่เปลี่ยน partition table, OTA flasher, SD firmware updater, HAL, display driver หรือ FreeInk power manager
- เปลี่ยนเฉพาะเส้นทางควบคุมในแอปหลักเพื่อรองรับ timer wake ของ Sleep Screen บน X3 และ pin checksum ไว้ใน safety gate

## วิธีติดตั้งผ่าน SD card

1. ดาวน์โหลด `crosspointTH-firmware.bin`
2. ตรวจสอบค่า SHA-256
3. เปลี่ยนชื่อไฟล์เป็น `firmware.bin` แล้ววางไว้ที่ root ของ SD card
4. เลือก **Settings → System → SD Card Firmware Update**

สามารถติดตั้งผ่าน USB Web Flasher ได้เช่นกัน โดยเลือก X3 หรือ X4 ให้ตรงกับอุปกรณ์และใช้โหมด Custom `.bin`

ห้ามตัดไฟ ปิดเครื่อง หรือถอดสายระหว่างอัปเดต รุ่นนี้ยังเป็น Pre-release จึงควรสำรองไฟล์ใน SD card และเก็บ
firmware รุ่นเดิมไว้สำหรับย้อนกลับ การอัปเดต Sleep Screen แบบทุก 5 นาทีควรทดสอบการใช้แบตเตอรี่บน X3 เพิ่มเติม
